## 🌟 Executive Overview

**JANAVYUH** replaces reactive, complaints-driven municipal administration with proactive, closed-loop sovereign civic intelligence:

1. **🎙️ Universal Multilingual Voice/Text Intake (MANTHAN AI)**: Ingests unstructured citizen grievances across WhatsApp voice notes, IVR, SMS, and field kiosks with neuro-symbolic intent recognition across 12+ regional languages.
2. **🧩 Semantic & Spatial Clustering (JANAGRAPH)**: Fuses fragmented reports into high-confidence need clusters using HDBSCAN embeddings while preserving 100% of raw submissions as sovereign evidence.
3. **🗺️ Regional Black GIS Topography**: Live spatial radar distinguishing critical distress hotspots (e.g. *Velachery*) from under-reported *"Silent Zones"* (e.g. *Sholinganallur*) to eliminate funding allocation bias.
4. **🔮 Counterfactual Simulation Lab**: Policy Time Machine testing trade-offs between capital expenditure, lifecycle maintenance, and population coverage through 10,000 Monte-Carlo scenario runs.
5. **⚖️ Multi-Agent Policy Arena (NIRNAY)**: Six specialized adversarial agents (Equity, Impact, Budget, Resilience, Infrastructure, Evidence) deliberate on civic evidence to produce transparent consensus recommendations.
6. **🏛️ Human Authority & Warrant Signing (Decision Desk)**: Consequential budget authorization remains strictly under human official authority with cryptographic sign-off.
7. **📜 Causal Impact Verification Ledger (PRAMAN)**: Closes the accountability loop by comparing pre-intervention predictions against post-delivery physical sensor feeds using tamper-proof cryptographic receipts.

## 🚀 1-Click Vercel Deployment (From GitHub)

This repository is optimized for **native 1-click deployment on Vercel**:

1. **Push code to your GitHub repository**:
   ```bash
   git add .
   git commit -m "feat: JANAVYUH React + Python Vercel deployment ready"
   git push origin main
   ```
2. **Deploy on Vercel**:
   - Go to **[vercel.com](https://vercel.com)** and log in with your GitHub account.
   - Click **"Add New..."** &rarr; **"Project"**.
   - Select your GitHub repository and click **"Import"**.
   - Vercel automatically detects the Vite React frontend and reads `vercel.json`.
   - Click **"Deploy"**.

Your application will build in ~60 seconds and go live with global edge CDN caching and automatic HTTPS!

## 💻 Local Development Setup

### 1. Prerequisites
- **Node.js** (v18.0 or newer)
- **Python** (v3.10 or newer)

### 2. Install & Run Frontend (React + Vite)
```bash
# Clone the repository
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>

# Install frontend dependencies
npm install

# Start Vite dev server
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 3. Run Python Backend (FastAPI) Locally
```bash
# Install Python dependencies
pip install -r requirements.txt

# Start FastAPI server
uvicorn api.index:app --reload --port 8000
```
API documentation is automatically available at **`http://localhost:8000/docs`**.

### 4. Build Production Bundle
```bash
npm run build
```
Generates an optimized static bundle in the `dist/` directory in under 2 seconds.
